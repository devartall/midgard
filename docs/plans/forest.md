# Лесная проверка

Цель: запускаемая соло-версия по game-speck.md на обычной сложности для iPhone 12 / Chrome.

Технический выбор: Canvas 2D с фиксированной изометрией, ES modules, Node.js для локального сервера и тестов. Без внешних зависимостей и загрузки ресурсов из сети.

Этапы:

- [x] Мир, сенсорное управление, сбор ресурсов, интерфейс.
- [x] Дом из частей, крафт, еда, навыки, сохранения.
- [x] Три противника, ночь и набеги, босс, смерть и возврат вещей.
- [x] Детерминированные проверки, сборка, инструкция запуска и ручной проверки.

Рабочие решения для проверки: меч и лук, блок без контрудара; гексагональный участок радиусом 5 клеток с тонкими стенами на рёбрах; закрытые стены/двери вокруг пола образуют убежище; крыша условно скрыта для обзора. Цикл дня 8 минут (5 день, 3 ночь). Цифры являются стартовым балансом и требуют проверки человеком. Первая ночь без разрушителей, если функциональная стоимость базы ниже порога. Без магии, онлайна и переноса дома.

Проверка: автоматические сценарии логики, интерфейса и ввода, синтаксическая проверка, статическая сборка и HTTP-выдача файлов. Настоящий браузер в окружении отсутствует; визуальная проверка, ощущения управления и FPS на iPhone остаются для ручной сессии.

Дополнение «Мидгард»: выполнены скандинавское оформление и иконки, сетка сумки и пояс 1–9, зелья, массовое строительство протягиванием, соединённые стены с проверкой радиуса движения, озёра/скалы и скопления врагов. Сохранения обновляются без потери инвентаря и дома.
