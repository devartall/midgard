# Лесной очаг

Играбельная лесная проверка браузерной survival-игры по [game-speck.md](game-speck.md). Соло, обычная сложность, один постоянный лес, три обычных вида монстров и первый босс. Графика — процедурная изометрия Canvas 2D, без загружаемых ассетов и внешних зависимостей.

## Запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна.

```sh
npm run dev
```

Откройте `http://localhost:5173`. Сервер слушает все интерфейсы. При запуске на компьютере в одной Wi-Fi-сети с iPhone откройте на телефоне `http://<локальный-IP-компьютера>:5173`. Для удалённого рабочего окружения потребуется доступный пользователю preview / проброс порта; `localhost` телефона не указывает на удалённый сервер.

```sh
npm run check
npm test
npm run build
```

Сборка создаёт `dist/`, пригодный для любого статического HTTP-хостинга. Для локальной проверки сборки: `SERVE_DIR=dist PORT=5174 npm start`. Открытие `index.html` через `file://` не поддерживается из-за ES modules.

## Первая сессия

1. Двигайтесь левым сенсорным кругом или WASD. Подойдите к дереву, камню или ягодам и нажмите кнопку действия / E. На карте M видны дом, могилы и древний круг.
2. Соберите дерево, отметьте участок через «Строить». Положите пол, затем стены по краям и дверь. Небольшая комната 5×5 клеток оставит достаточно места для обстановки. Детали размещаются касанием клетки после выбора в меню; «Готово» выходит из размещения.
3. Постройте очаг и верстак. У верстака создайте меч; после охоты будут доступны лук и броня. У очага готовьте мясо. Съесть еду можно в сумке. Закрытое помещение с полом и очагом позволяет восстанавливать здоровье в покое, когда персонаж сыт и рядом нет монстров.
4. На пятой минуте начинается ночь, длительностью три минуты. Если есть оборудование дома, сначала появится 25-секундное предупреждение о набеге. От 28 единиц функциональной стоимости приходит разрушитель. Украшения и обычные стены не повышают угрозу.
5. В бою используйте удар, удержание блока и точный контрудар. Промах контрудара временно не позволяет прикрыться блоком. Лук расходует стрелы. Изучайте записи на камнях и хранителя в северо-восточной части карты. Его вторая фаза добавляет круговую атаку; после проигранной попытки здоровье восстанавливается полностью.
6. После смерти выберите старт или домашнюю лежанку. Вещи остаются на месте гибели без таймера удаления. Монстры не уничтожают складские запасы, но их близость блокирует использование оборудования.

## Сохранение

Автоматически каждые 10 секунд активной игры, после основных действий, при паузе и уходе со страницы. Мир не продвигается в фоне или закрытом браузере. В меню паузы есть ручное сохранение и экспорт/импорт JSON-копии; импорт и новый мир требуют подтверждения. Аккаунта и синхронизации нет. Очистка данных браузера удаляет локальное сохранение.

## Проверка на iPhone 12 / Safari и Chrome

Браузерные и физические тесты в среде разработки не выполнялись: установленного браузера нет. Автоматические проверки Canvas/DOM используют тестовые адаптеры и не подтверждают внешний вид, FPS или удобство.

- Игровая область: длительные свайпы по миру и стику, второй палец на блоке/ударе, отпускание пальцев в разном порядке. Страница не должна двигаться или пружинить, управление не должно залипать. Длинное меню крафта должно по-прежнему прокручиваться внутри панели.
- Горизонтальный экран: доступность кнопок большими пальцами, отсутствие перекрытия интерфейса вырезом и нижней полосой; движение одновременно с атакой и блоком.
- Строительство: точность попадания в клетку, читаемость стен и персонажа, проход через дверь, работа закрытого убежища.
- Анимации: бег и остановка героя, волка, скитальца, разрушителя и босса; замахи и удары, выстрел из лука, остановка анимаций на паузе. Проверить детализацию построек, открытые двери и руины при разном освещении.
- Бой: читаемость подготовки атак, окно контрудара, возможность уйти от круговой атаки босса, различимость трёх противников.
- Свернуть и вернуть Chrome, заблокировать телефон, повернуть экран: нет скрытого расхода сытости и залипшего движения. Перезагрузить страницу и продолжить сохранение.
- Нападение на дом, когда персонаж далеко: предупреждение и счётчик; возвращение, освобождение сундука и ремонт. Смерть около занятого дома не лишает выбора стартовой точки.

## Текущие ограничения

Это первая проверка механик, не законченная визуальная версия. Изображения рисуются геометрией, с процедурными анимациями бега и ударов, детализированными постройками и растительностью, без внешних текстурных ассетов и звука. Крыша условная: замкнутый контур стен/дверей над полом считается укрытием, отдельного размещения крыши нет. Лес пока не включает погодную угрозу. Навигация монстров простая; сложные лабиринты из стен требуют ручной проверки. Числа рецептов, времени, урона и опыта — стартовый баланс, длительность прохождения и производительность iPhone не измерены.

На личной обороне части дома могут разрушаться полностью, в отсутствие игрока остаются ремонтируемые руины. Штраф навыков за смерть не добавлен; перенос опыта у верстака теряет 20%. Магия, другие биомы, перенос дома, повышенная сложность и онлайн отложены.

Логика находится в `src/game.js`, отрисовка в `src/render.js`, интерфейс и жизненный цикл страницы в `src/main.js`. Тесты используют встроенный Node test runner.

Управление использует Pointer Events с отдельным захватом указателя для каждого органа управления. HTML/body закреплены без прокрутки; `touch-action: none` и непассивный WebKit fallback ограничены игровыми поверхностями, а меню сохраняют собственную прокрутку. Viewport meta и масштаб Canvas не менялись. Системные жесты iOS, начинающиеся вне содержимого страницы (например, вызов домашнего экрана), не контролируются веб-игрой.
